[README.md](https://github.com/user-attachments/files/28194464/README.md)# Botanica House

Botanica House is a botanical wellness tracking website designed to help users manage and monitor their indoor and outdoor plants in a calming and organized way.

The website combines plant care management with wellness-inspired design to create a relaxing digital gardening experience.

---

# Features Included

## Login System
- Demo login account provided
- Simple authentication using JavaScript and localStorage

## Plant Management
- Add plant information
- Upload plant images
- Store plant details locally

## Plant Care Calendar
- Track watering activities
- Track fertilizer usage
- Track soil care
- Track sunlight rotation
- Track leaf trimming

## Wellness Tracker
- Recovery progress bar
- Plant condition updates
- Status tracking:
  - Healthy
  - Recovering
  - Needs Attention
  - Critical
  - Archived

## Dashboard Analytics
- Total plants summary
- Indoor vs outdoor chart
- Healthy plants overview

## Wellness Tips
- Indoor gardening tips
- Outdoor gardening tips
- Plant wellness suggestions
